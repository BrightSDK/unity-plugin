Unity Plugin

Automated Unity Editor extension that downloads, updates, and integrates the BrightSDK into your Unity projects — Android, iOS, tvOS, macOS, and Windows.

Install Plugin View on GitHub

How It Works

The plugin hooks into Unity's IPreprocessBuildWithReport callback. Before every build, it automatically resolves the latest SDK version, downloads the archive, and extracts it into your project's Plugins folder.

Unity Build
→
Plugin (PreBuild)
→
downloader-rs FFI
→
SDK Archive
→
Assets/Plugins/

Since v1.1.0, the plugin uses bright-sdk-downloader-rs via P/Invoke (C# DllImport) for fast, native SDK resolution and download. The native library is auto-downloaded on first build — no manual setup required.

Features

⚡
Automatic SDK Updates Fetches and updates the Bright SDK before every build — always ship the latest.
🦀
Rust-powered Downloads Uses bright-sdk-downloader-rs native library via P/Invoke for fast, safe fetching.
📦
Zero Configuration Native library auto-downloads on first build. Just set your API key and build.
🔄
Version Management Pin specific SDK versions via BrightSDK.json config, or use latest to always get the newest.
🧹
Clean Up Removes obsolete SDK files before extraction to prevent conflicts.
🔒
Graceful Fallback If the native library is unavailable, falls back to HTTP-based download — always builds.

Installation

Step 1 — Add SharpZipLib dependency

  1. Open Window → Package Manager
  2. Click + → Add package by name
  3. Enter com.unity.sharp-zip-lib
  4. Click Add

Step 2 — Install the plugin

macOS / Linux:

# cd to your Unity project directory
wget https://raw.githubusercontent.com/BrightSDK/unity-plugin/refs/heads/main/install_dependencies.sh \
  -O install_dependencies.sh && chmod +x install_dependencies.sh && \
  ./install_dependencies.sh && rm install_dependencies.sh

wget https://raw.githubusercontent.com/BrightSDK/unity-plugin/refs/heads/main/install.sh \
  -O install.sh && chmod +x install.sh && ./install.sh && rm install.sh

Windows (PowerShell):

Invoke-WebRequest https://raw.githubusercontent.com/BrightSDK/unity-plugin/refs/heads/main/install_dependencies.ps1 `
  -OutFile install_dependencies.ps1; .\install_dependencies.ps1; Remove-Item install_dependencies.ps1

Invoke-WebRequest https://raw.githubusercontent.com/BrightSDK/unity-plugin/refs/heads/main/install.ps1 `
  -OutFile install.ps1; .\install.ps1; Remove-Item install.ps1

Step 3 — Set your API key

environment variable
export SDK_API_KEY=my-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

API Key

The plugin authenticates via the SDK_API_KEY environment variable.

  1. Log in to the BrightSDK Control Panel → API keys
  2. Click + Add, choose an expiration, name the key, click Generate key
  3. Copy the key immediately — it is shown only once
  4. Export it: 
    export SDK_API_KEY=<your-api-key>

Usage

The plugin runs automatically during the build process:

  1. Open File → Build Settings
  2. Select your target platform
  3. Click Build or Build and Run

That's it. The SDK will be fetched and placed into Assets/Plugins/ before the build begins.

Customization

Pin specific SDK versions in Assets/Editor/BrightSDK/BrightSDK.json: 

{
  "versions": {
    "android": "1.520.0",
    "appleMobile": null,
    "appleDesktop": null,
    "windows": null
  }
}

Set a value to pin that version, or null for latest.

Architecture

Component File Role
Prebuild Hook BrightSDKLoaderPrebuild.cs Entry point — orchestrates version resolution, download, extraction
FFI Bridge BrightSdkDownloaderFFI.cs P/Invoke calls to bright_sdk_download native library
Versions BrightSDKVersions.cs Resolves latest SDK versions (FFI → HTTP fallback)
Downloader BrightSDKArchiveDownloader.cs HTTP-based archive download (fallback path)
Extractors BrightSDKExtractor.cs Platform-specific extraction (AAR, framework, DLL)
